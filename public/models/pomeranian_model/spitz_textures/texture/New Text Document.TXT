# Detailed Photoshop Instructions for Converting Fur Texture to Black Pomeranian

## Step 1: Preparation
1. Open your texture in Photoshop
2. Duplicate your background layer (Ctrl+J or Cmd+J) to preserve the original
3. Name this new layer "Black Fur Base"

## Step 2: Create Selection for Non-Fur Areas
1. Use the Quick Selection tool (W) to select non-fur areas:
   - The eye in the top left
   - Pink/reddish areas (tongue, inner mouth)
   - The paw pads (dark areas with distinct shape)
   - Any other anatomical features you want to preserve
2. Save this selection: Select > Save Selection
   - Name it "Non-Fur Areas"
3. Invert your selection (Shift+Ctrl+I or Shift+Cmd+I) to select only the fur
4. Save this selection as "Fur Only"

## Step 3: Apply Black Fur Color
1. With "Fur Only" selection active, create a new adjustment layer:
   - Layer > New Adjustment Layer > Hue/Saturation
   - Name it "Black Fur Color"
2. In the Properties panel:
   - Check "Colorize" box
   - Set Hue: 0
   - Set Saturation: 0
   - Set Lightness: -70
3. The mask will automatically apply to your selection

## Step 4: Enhance Fur Texture
1. With "Fur Only" selection still active, add another adjustment layer:
   - Layer > New Adjustment Layer > Brightness/Contrast
   - Name it "Fur Texture Enhancement"
2. In the Properties panel:
   - Set Brightness: -40
   - Set Contrast: +15

## Step 5: Fine-Tune the Black Fur
1. Create a new Curves adjustment layer (Layer > New Adjustment Layer > Curves)
   - Name it "Fur Depth"
   - Make a slight S-curve by adding points and dragging:
     - Add a point at input 128, move to output ~100
     - Add a point at input 200, move to output ~180
2. This gives the black fur more dimension and depth

## Step 6: Add Subtle Variation (Optional but Recommended)
1. Create a new layer (Ctrl+Shift+N or Cmd+Shift+N)
   - Name it "Fur Variation"
   - Set blend mode to "Soft Light"
   - Fill with 50% gray (Edit > Fill > 50% Gray)
2. With a soft brush at 10-15% opacity:
   - Paint with a very dark brown (#1A1410) in some areas
   - Paint with pure black (#000000) in other areas
   - Use very subtle strokes following the fur direction
3. Keep the opacity of this layer around 20-30%

## Step 7: Final Adjustments
1. Add a final "Color Balance" adjustment layer
   - Set Shadows to slight blue tint (-5, 0, +5)
   - Set Midtones to slight red tint (+5, 0, 0)
2. Adjust the opacity of any layers as needed for the most realistic look

## Step 8: Save Your Work
1. Save as PSD to preserve all layers
2. Export as PNG for use in Blender:
   - File > Export > Export As
   - Choose PNG format
   - Check "Alpha Channels" if your texture uses transparency

Remember to periodically toggle the visibility of your adjustment layers to compare with the original and ensure you're maintaining good texture detail while changing the color.
